# Auto World Backup for Minecraft 1.7.10

サーバーだけに導入する、自動ワールドバックアップ Mod です。

- バックアップ直前に全ワールドを保存
- 保存を一時停止してワールドフォルダーを ZIP 化
- 完了または失敗後に保存を再開
- 古い ZIP を設定した世代数まで自動整理
- `/autobackup now` で手動バックアップ
- `/autobackup status` で状態確認

## 導入

1. ダウンロードした.jarをmodsにぶち込んで完了。

## 初期設定

- バックアップ先: サーバールートの `backups`フォルダ
- 実行間隔: 60分
- 起動後の初回実行: 5分後
- 保持世代: 24個
- 対象: `server.properties` の `level-name` に対応するワールドフォルダー全体

バックアップ先をワールドフォルダーの内側に設定することはできません。

## コマンド

サーバーコンソール、または権限レベル4のプレイヤーが実行できます。

```text
/autobackup now
/autobackup status
```

## 復元

1. サーバーを停止します。
2. 現在のワールドフォルダーを別の場所へ退避します。
3. ZIP をサーバールートへ展開します。
4. サーバーを起動します。

## ビルド

Java 8で実行します。

```powershell
.\gradlew.bat build
```

生成先は `build/libs/AutoWorldBackup-1.0.0.jar` です。
